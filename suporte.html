Suporte

Ferramentas para deixar o Windows 11 mais leve e limpo.

Ativador do Windows

Script de ativação executado pelo PowerShell.

  1. Abra o PowerShell ou o Terminal.
  2. Copie o comando abaixo e cole no PowerShell.
irm https://get.activated.win | iex

RyTuneX

Assuma o controle do Windows. O RyTuneX é uma ferramenta de ajustes avançados e de código aberto, criada para usuários avançados e jogadores que querem mais desempenho, menos latência e mais privacidade.

Abrir na Microsoft Store

Win11Debloat

Script que remove aplicativos pré-instalados e ajusta configurações do Windows. Projeto de código aberto: github.com/raphire/win11debloat

Método rápido

Baixe e execute o script automaticamente pelo PowerShell.

  1. Abra o PowerShell ou o Terminal.
  2. Copie o comando abaixo e cole no PowerShell.
& ([scriptblock]::Create((irm "https://debloat.raphi.re/")))

Antes de executar qualquer script baixado da internet, leia o código no repositório para saber o que ele vai alterar no seu computador.
